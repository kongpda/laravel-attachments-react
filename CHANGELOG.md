# Changelog

## Unreleased

## 0.2.0 - 2026-09-21

### Added

- The upload queue: `useUploadQueue`, `xhrUpload`, `xhrPut`, `UploadError`,
  `FileDropzone` and `UploadTile`.
- `SortableMediaGrid` and `SortableMediaTile` at
  `@kongpda/laravel-attachments-react/sortable`, with optional `@dnd-kit`
  peers.
- CommonJS build and typed conditional exports.

### Fixed

- Image cards use `thumbnail_url` and fall back to the original.
- The Open link is no longer a button inside a link.
- A caption changed on the server replaces the local draft.
- Replaced the deprecated `React.ElementRef`.
